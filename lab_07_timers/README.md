1. Сигнал ШИМ, длительность импульса, коэффициент заполнения
ШИМ (PWM — Pulse Width Modulation) — периодический прямоугольный сигнал с постоянной частотой и переменной шириной импульса.

Длительность импульса (pulse width, t_on) — время, в течение которого сигнал находится в высоком состоянии (HIGH) за один период.
Коэффициент заполнения (duty cycle, D) — отношение длительности импульса к периоду сигнала, выражается в процентах:

D = t_on / T × 100%
Например, D = 50% означает, что сигнал половину периода HIGH, половину — LOW. Применяется для управления яркостью светодиодов, скоростью моторов, среднее напряжение на нагрузке.

2. Базовые таймеры vs таймеры общего назначения
Базовые таймеры (TIM6, TIM7 в STM32H745):

Только счётчик вверх (up-counting)
Нет каналов захвата/сравнения
Нет GPIO-выводов, связанных с таймером
Могут генерировать события Update и триггер для DAC
Используются как источник тактирования для DAC или простой задержки/прерывания
Таймеры общего назначения (TIM2–TIM5, TIM12–TIM17 и др.):

Несколько каналов захвата/сравнения (Input Capture / Output Compare / PWM)
Счёт вверх, вниз, вверх-вниз (center-aligned)
Поддержка энкодера
Связанные GPIO-выводы (alternate function)
Поддержка DMA на каналах
Режим One Pulse Mode
3. Advanced Control таймеры vs таймеры общего назначения
Advanced Control таймеры (TIM1, TIM8 в STM32H745) имеют всё, что у General Purpose, плюс:

Комплементарные выходы (CHxN) с «мёртвым временем» (dead-time) — для управления мостовыми схемами (H-bridge), где нельзя одновременно открыть оба ключа
Break input (BRK/BRK2) — аварийный останов (защита от КЗ, перегрева)
Repetition Counter (RCR) — событие Update генерируется не каждый период, а через N периодов
Управление выходами через MOE (Main Output Enable) бит — выходы по умолчанию отключены, нужно явно разрешить
Поддержка 6-шагового управления (для трёхфазных инверторов)
4. Режимы синхронизации таймеров
Таймеры STM32 могут быть связаны в цепочку Master→Slave через сигналы TRGO/ITR:

Режим (SMCR.SMS)	Описание
Reset Mode	Внешний сигнал (триггер) сбрасывает счётчик в 0
Gated Mode	Счётчик считает только когда триггер HIGH; останавливается когда LOW
Trigger Mode	Триггер запускает счётчик (он не работал до прихода сигнала)
External Clock Mode 1	Счётчик тактируется фронтами внешнего сигнала через TRGI
External Clock Mode 2	Тактирование через вход ETR (External Trigger)
Encoder Mode 1/2/3	Декодирование квадратурного энкодера (по фронтам CH1, CH2, или обоим)
Источники триггера (TRGI): внутренние ITR0–ITR3 (от другого таймера), TI1F_ED (оба фронта CH1), TI1FP1, TI2FP2, ETRF.

5. Основные регистры базового таймера
Регистр	Название	Назначение
CR1	Control Register 1	Включение счётчика (CEN), направление (DIR), режим one-pulse (OPM), включение авто-перезагрузки (ARPE)
CR2	Control Register 2	Настройка TRGO (Master Mode Selection, MMS) — что передаётся как триггер другим таймерам
DIER	DMA/Interrupt Enable Register	Разрешение прерывания/DMA по событию Update (UIE/UDE)
SR	Status Register	Флаги событий: UIF (Update Interrupt Flag)
EGR	Event Generation Register	Программная генерация событий: UG — принудительный Update
CNT	Counter	Текущее значение счётчика
PSC	Prescaler	Делитель тактовой частоты (делит на PSC+1)
ARR	Auto-Reload Register	Значение, до которого считает счётчик (период). Загружается в теневой регистр при Update
Частота Update: f_UE = f_CK_PSC / ((PSC+1) × (ARR+1))

6. Функциональные режимы таймеров общего назначения
Output Compare (OC) — сравнение CNT с CCRx, действие на выходе при совпадении (Toggle, Set, Reset, Force)
PWM Mode 1/2 — генерация ШИМ (частный случай OC)
Input Capture (IC) — захват значения CNT по фронту/спаду внешнего сигнала в CCRx
One Pulse Mode (OPM) — генерация одного импульса заданной длины по триггеру
Encoder Mode — подсчёт импульсов квадратурного энкодера
Slave/Master синхронизация — синхронная работа нескольких таймеров
Center-aligned PWM — ШИМ с центрированием (счёт вверх-вниз)
7. Режим ШИМ (PWM Mode)
В STM32 ШИМ реализован через Output Compare с особой логикой:

Счётчик (CNT) считает от 0 до ARR (период = ARR+1 тиков)
PWM Mode 1: выход HIGH пока CNT < CCRx, LOW когда CNT ≥ CCRx
PWM Mode 2: инверсия — выход LOW пока CNT < CCRx, HIGH когда CNT ≥ CCRx
Изменение CCRx меняет duty cycle. При ARPE=1 CCRx загружается через теневой регистр (только при Update), что предотвращает глитчи

Duty Cycle = CCRx / (ARR + 1) × 100%
Выход подаётся на GPIO через Alternate Function.

8. Режим входного захвата (Input Capture)
Настраивается фильтр и делитель входного сигнала (CCMR1: ICxF, ICxPSC)
Выбирается полярность (CCER: CCxP — Rising/Falling/Both)
По наступлению фронта на входе CHx: текущее значение CNT копируется в CCRx
Генерируется прерывание/DMA запрос CCxIF
Применение: измерение периода, длительности импульса, частоты
Измерение длительности импульса (как в вашем tim_mesure):

1-й захват по нарастающему фронту → CCR = t_start
2-й захват по спадающему фронту → CCR = t_end
Длительность = (t_end − t_start) / f_ticks
9. Режим сравнения-вывода (Output Compare)
Счётчик CNT непрерывно сравнивается с CCRx
При совпадении (CNT == CCRx) на выходе CHx происходит действие, задаваемое полем OCxM в CCMR:
Frozen — ничего (только флаг/прерывание)
Set — выход HIGH
Reset — выход LOW
Toggle — инверсия выхода
Force High/Low — принудительная установка
Используется для генерации точных задержек, управления несколькими событиями в одном периоде
10. Режим One Pulse Mode (OPM)
Генерирует один импульс заданной длины по внешнему триггеру:

Таймер остановлен (CEN=0) или настроен как Slave
По приходу триггера (Slave Trigger Mode = Trigger Mode) CNT сбрасывается и CEN устанавливается автоматически
Выход HIGH устанавливается с задержкой CCR1 тиков, LOW — при достижении ARR
При OPM=1 (CR1 бит): после достижения ARR таймер автоматически останавливается (CEN=0)
Длина задержки = CCR1, длина импульса = ARR − CCR1 (в тиках).

11. Режим энкодера (Encoder Mode)
Входы CH1 и CH2 подключаются к сигналам A и B квадратурного энкодера
SMS биты (SMCR) выбирают режим:
001 — счёт только по фронтам TI1 (CH1)
010 — счёт только по фронтам TI2 (CH2)
011 — счёт по фронтам обоих каналов (×4 разрешение)
Направление вращения определяется по фазовому сдвигу между A и B: если A опережает B — CNT инкрементируется, иначе — декрементируется
CNT содержит абсолютное положение; при переполнении/антипереполнении счёт продолжается
Используется для позиционирования, измерения скорости вращения
12. Работа таймеров в режимах сна и остановки
Sleep Mode (WFI/WFE, тактирование CPU остановлено, периферия работает):

Таймеры продолжают работать — они тактируются от шины APB, которая не останавливается
Прерывания от таймеров пробуждают ядро
Stop Mode (тактирование всей высокоскоростной периферии останавливается):

Все таймеры останавливаются (APB clock выключен)
Счётчик «замирает», CNT сохраняет значение
Пробудить от Stop-режима могут только LPTIM (Low Power Timer) или внешние прерывания EXTI
LPTIM1/LPTIM2 — специальные таймеры, работающие от LSI/LSE (32 кГц) даже в Stop-режиме, используются для периодического пробуждения.

13. Расчёт частоты события Update

f_UE = f_TIM_CLK / ((PSC + 1) × (ARR + 1))
Где:

f_TIM_CLK — частота тактирования таймера (зависит от шины APB и умножителя, для STM32H745 при полной скорости до 240 МГц на APB1/APB2 при коэффициенте ×2)
PSC — значение регистра Prescaler
ARR — значение регистра Auto-Reload
Пример из вашего tim_mesure.h: PSC=63, ARR=65535, f_TIM=64 МГц:


f_UE = 64_000_000 / (64 × 65536) ≈ 15.26 Гц → период ≈ 65.5 мс
14. Действия при событии Update (Update Event, UE)
При достижении CNT значения ARR (или 0 в down-counting) происходит:

Сброс/перезагрузка CNT (в 0 при up-counting)
Загрузка теневых регистров: значения PSC и ARR из «предзагрузочных» регистров копируются в рабочие (если ARPE=1/PSCRST=1)
Загрузка CCRx из теневых (если OCxPE=1 для соответствующего канала) — актуально для ШИМ без глитчей
Установка флага UIF в SR
Если UIE=1 → генерация прерывания
Если UDE=1 → генерация DMA-запроса
Если настроен как Master → генерация TRGO сигнала для подчинённых таймеров
15. Конфигурация входного канала таймера
Каждый канал CHx имеет настраиваемый тракт обработки сигнала (регистры CCMRx при ICxS, ICxF, ICxPSC):


Физический вывод GPIO
        ↓
[Фильтр ICxF] — подавление помех (0–15: от 1 до 32768 выборок)
        ↓
[Делитель ICxPSC] — захват каждые 1/2/4/8 событий
        ↓
[Мультиплексор ICxS] — выбор источника:
  • TI1 (собственный канал)
  • TI2 (соседний канал — перекрёстный захват)
  • TRC (внутренний триггер)
        ↓
[Детектор фронта CCER: CCxP/CCxNP] — Rising/Falling/Both
        ↓
[CCRx] — значение CNT при событии
Перекрёстный захват (IC1 на TI2, IC2 на TI1) позволяет одновременно измерять период и длительность импульса одного сигнала.

16. Источники тактирования таймеров
Источник	Описание
Internal clock (CK_INT)	Тактирование от шины APB (через RCC), основной режим
External clock Mode 1	Фронты на TIx (входных каналах) тактируют счётчик
External clock Mode 2	Вход ETR (External Trigger) — отдельный пин
Internal Trigger (ITRx)	TRGO другого таймера (цепочка Master→Slave)
TI1F_ED	Любой фронт (нарастающий или спадающий) канала TI1
В STM32H745 частота шины APBx умножается на 2 (если делитель APB ≠ 1), поэтому при конфигурации RCC нужно это учитывать. Для H745 при стандартной конфигурации: TIMx на APB1 получают 240 МГц, TIMx на APB2 — тоже 240 МГц.

17. Контроллер DMA и режимы работы
DMA (Direct Memory Access) — контроллер, выполняющий передачу данных между периферией и памятью (или память↔память) без участия CPU.

Режимы работы:

Режим	Описание
Peripheral→Memory	Данные с периферии (например, CCRx таймера) → буфер в RAM
Memory→Peripheral	Данные из RAM → в периферию (например, DAC)
Memory→Memory	Копирование внутри памяти
Normal (Single)	Передаёт заданное количество элементов и останавливается; генерирует прерывание TC (Transfer Complete)
Circular	По завершении автоматически начинает заново — бесконечный цикл; полезен для периодических данных
Double Buffer	Два буфера попеременно — пока DMA пишет в один, CPU читает другой
FIFO / Direct	FIFO режим позволяет burst-передачи для эффективного использования шины AHB
18. Количество DMA контроллеров в STM32H745ZI-Q
В STM32H745ZI-Q имеется 3 контроллера DMA:

DMA1 — для периферии на домене D2 (таймеры, UART, SPI и др.)
DMA2 — для периферии на домене D2 (более высокоприоритетные запросы)
BDMA (Basic DMA) — для периферии домена D3 (LPUART1, SPI6, I2C4 и др.), работает в Stop-режиме
19. Количество потоков DMA в STM32H745ZI-Q
DMA1: 8 потоков (Stream 0–7)
DMA2: 8 потоков (Stream 0–7)
BDMA: 8 каналов (Channel 0–7)
Итого: 24 потока/канала DMA.

Каждый поток имеет отдельный FIFO (4 × 32 бит) и независимые настройки приоритета.

20. Коммутация запроса DMA с периферией в HAL
В HAL настройка выполняется через структуру DMA_HandleTypeDef и поле Request:


// Из вашего tim_mesure.h:
#define TIMm_DMA_REQUEST DMA_REQUEST_TIM5_CH1

DMA_HandleTypeDef hdma;
hdma.Init.Request = DMA_REQUEST_TIM5_CH1;  // DMAMUX маршрутизация
hdma.Init.Direction = DMA_PERIPH_TO_MEMORY;
hdma.Init.PeriphInc = DMA_PINC_DISABLE;
hdma.Init.MemInc = DMA_MINC_ENABLE;
// ...
HAL_DMA_Init(&hdma);

// Связывание DMA с таймером:
__HAL_LINKDMA(&hTimMesure, hdma[TIM_DMA_ID_CC1], hdma);
HAL автоматически записывает нужное значение в регистр DMAMUX при HAL_DMA_Init().

21. Коммутация запроса DMA с периферией на уровне железа (DMAMUX)
В STM32H7 используется DMAMUX (DMA Request Multiplexer) — специальный блок между периферией и DMA:


Периферия (TIM5_CH1) ──→ [DMAMUX1] ──→ DMA1/DMA2 Stream
Периферия (SPI1_RX)  ──→ [DMAMUX1] ──→ DMA1/DMA2 Stream
...
Периферия на D3      ──→ [DMAMUX2] ──→ BDMA Channel
DMAMUX1 обслуживает DMA1 и DMA2 (16 каналов = 8+8 потоков)
DMAMUX2 обслуживает BDMA (8 каналов)
Каждый канал DMAMUX имеет регистр CxCR с полем DMAREQ_ID, куда записывается номер периферийного запроса
Например: TIM5_CH1 = 57 (из таблицы Reference Manual)
HAL скрывает это через константу DMA_REQUEST_TIM5_CH1
22. Режимы ШИМ в таймерах общего назначения STM32
Режим	OCxM код	Описание
PWM Mode 1	110	HIGH пока CNT < CCRx, LOW когда CNT ≥ CCRx
PWM Mode 2	111	Инверсия: LOW пока CNT < CCRx, HIGH когда CNT ≥ CCRx
Combined PWM Mode 1	—	Комбинация на смежных каналах (OC6REF AND OC5REF)
Combined PWM Mode 2	—	Комбинация (OC6REF OR OC5REF)
Asymmetric PWM Mode 1/2	—	Для center-aligned: разные точки включения и выключения
Основные — PWM Mode 1 и 2. В center-aligned (up-down counting) ШИМ симметричен относительно центра периода, что снижает гармоники — актуально для управления двигателями.

Поляярность инвертируется битом CCxP (CCER регистр), что даёт ещё 2 варианта для каждого режима.

23. * Зачем нужен буфер (FIFO) в контроллере DMA?
Проблема без FIFO (Direct Mode): каждый DMA-запрос от периферии немедленно инициирует транзакцию на шине AHB. Если шина занята (другим мастером), запрос ожидает. Периферия тем временем может переполниться.

FIFO решает несколько задач:

Burst-передачи: DMA накапливает данные в FIFO (1–4 слова), затем передаёт их шиной одним burst-пакетом (INCR4/INCR8/INCR16). Это эффективнее одиночных транзакций — меньше арбитражных накладных расходов.

Согласование ширины данных: периферия может работать с байтами (8 бит), а память — с 32-битными словами. FIFO накапливает 4 байта и записывает одним 32-битным словом — шина используется эффективнее.

Развязка по времени: периферия пишет в FIFO когда готова, DMA читает из FIFO когда шина свободна. Пропускная способность выравнивается.

Double Buffer совместимость: FIFO позволяет DMA переключать буферы без прерывания потока данных.

В вашем случае (TIM5 IC + DMA): при высокой частоте захватов FIFO позволяет DMA не терять данные даже при кратковременной занятости шины AHB другими мастерами (CPU, другой DMA-поток).

Вопросы охватывают весь материал лабораторной работы — от базовой теории ШИМ до архитектуры DMAMUX в STM32H745.
